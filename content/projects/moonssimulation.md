**Computer Simulation of Jupiter’s Lunar Orbits** is a computational physics project developed during an academic exchange at Northeastern Illinois University (NEIU). The project uses Python to explore and visualize the orbital motion of Jupiter’s moons through numerical simulation, combining physical modeling, scientific programming, and data visualization to study celestial mechanics.

### Key Highlights
- **Orbital Mechanics:** Explored the motion of Jupiter’s natural satellites through computational modeling of their orbital trajectories.
- **Numerical Simulation:** Applied Python programming to simulate orbital behavior and represent the evolution of celestial bodies over time.
- **Scientific Visualization:** Generated visual representations of lunar orbits to facilitate the interpretation of orbital dynamics.
- **Computational Physics:** Connected theoretical physics concepts with numerical methods to investigate planetary systems.
- **International Academic Experience:** Developed the project during an academic exchange at NEIU, strengthening scientific programming and cross-cultural academic collaboration.

### Tech Stack & Methodology
- **Scientific Computing (`Python`):** Implementing computational models to represent and simulate orbital motion.
- **Interactive Analysis (`Jupyter Notebook`):** Organizing simulation code, running computational experiments, and visualizing results.
- **Version Control (`Git`):** Tracking code changes and maintaining the project’s source code.

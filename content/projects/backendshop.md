**Admin Shop App** is a basic e-commerce web application focused on backend development, authentication, and access control. The project implements essential user management features, including account registration, login, and administrator access, providing a foundation for managing an online shopping platform with role-based permissions.

### Key Highlights
- **User Authentication:** Implemented registration and login workflows to manage user accounts and authenticated sessions.
- **Role-Based Access Control:** Separated regular user access from administrator privileges to protect restricted functionality.
- **Backend-Centered Architecture:** Focused on developing and integrating server-side functionality with the frontend application.
- **E-Commerce Foundation:** Built a basic shopping application structure that can be extended with product management and additional store features.
- **Full-Stack Integration:** Connected the user interface with backend services to support authentication and access-controlled functionality.

### Tech Stack & Architecture
- **Frontend (`Vue.js + JavaScript`):** Building the user interface for authentication and shopping-related functionality.
- **Development Environment (`Vite`):** Streamlining frontend development and production builds.
- **Backend (`NestJS`):** Implementing server-side application logic, authentication, and authorization.
- **Deployment (`Railway`):** Deploying the application and making its functionality accessible through a public URL.

**Maps App** is a lightweight web-based mapping application designed to simplify navigation and route planning through an interactive map interface. The application uses geolocation to display the user's current position, enables address searches, and calculates routes between locations, providing estimated travel distances and times.

### Key Highlights
- **Real-Time Geolocation:** Displays the user's current location on an interactive map using geolocation services.
- **Address Search:** Allows users to search for addresses and identify destinations on the map.
- **Route Planning:** Generates routes between locations to help users navigate from their starting point to their destination.
- **Distance and Travel Time:** Calculates route distances and estimated travel times to support trip planning.
- **Interactive Mapping:** Provides a dynamic map interface for exploring locations and visualizing navigation routes.

### Tech Stack & Development
- **Frontend (`Vue.js + JavaScript`):** Building the interactive user interface and managing map-related interactions.
- **Development Environment (`Vite`):** Providing a fast development workflow and optimized production builds.
- **Mapping Services (`Mapbox`):** Integrating interactive maps, location visualization, address search, and route information.
- **Deployment (`Railway`):** Hosting the application and making it accessible through a public web interface.

**USchedU** is a university course scheduling platform designed to help students build optimized class schedules based on their academic requirements and personal preferences. Originally developed as Horarios Guapos, the project aims to simplify course planning through automated schedule generation and constraint-based optimization, with the long-term goal of expanding to multiple universities.

### Key Highlights
- A**utomated Schedule Generation:** Generates valid class schedules while considering course groups, class times, and scheduling conflicts.
- **Constraint-Based Optimization:** Explores schedule combinations to accommodate student preferences, including fewer university days, earlier classes, and reduced gaps between sessions.
- **Academic Planning:** Supports planning around required courses and compatible subjects from upcoming semesters.
- **Student-Centered Design:** Provides an accessible interface for exploring available courses and comparing alternative schedules.
- **Real-World Impact:** Reached over 3,000 visits in less than two months, demonstrating student interest in automated academic scheduling.

### Tech Stack & Architecture
- **Frontend (`React + TypeScript + Vite`):** Building a responsive user interface for course selection, schedule generation, and schedule visualization.
- **Optimization Algorithms (`Python`):** Applying algorithmic approaches to explore course combinations and satisfy scheduling constraints.
- **Data Management (`SQL`):** Supporting the planned evolution toward a structured data model for universities, degree programs, courses, and course offerings.
- **Schedule Export (`PDF`):** Enabling students to export generated schedules for convenient access and planning.
- **Scalable Architecture:** Evolving the project toward a multi-university platform with centralized academic data and more advanced optimization capabilities.

The **E.T. Remake** is an independent game development project inspired by the classic E.T. the Extra-Terrestrial video game. The project combines gameplay programming, pixel-art design, and audio production to recreate the retro gaming experience using modern development tools.

### Key Highlights
- **Gameplay Development:** Implementing game mechanics and interactive systems using Godot.
- **Pixel-Art Design:** Creating and refining retro-inspired visual assets with Aseprite.
- **Audio Production:** Developing music and audio assets using LMMS.
- I**ndependent Development:** Managing the project from implementation to visual and audio integration.

### Tech Stack & Development
- **Game Engine (`Godot`):** Developing gameplay logic, interactive systems, and the overall game architecture.
- **Pixel Art (`Aseprite`):** Designing and editing sprites and visual assets to maintain a consistent retro aesthetic.
- **Audio Production (`LMMS`):** Creating and editing music to enhance the game's atmosphere.
- **Version Control (`GitHub`):** Tracking source-code changes and organizing the development workflow.
